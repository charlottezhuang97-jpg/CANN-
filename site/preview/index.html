了解 CANN 社区 sig 运营

CANN 社区为开源 SIG 提供了一条可复用的运营路径：从认知运营体系与支撑组织开始，完成 sig 上线与仓开源推广，按日历申请公众号、视频号、媒体等渠道资源与奖品，再以运营计划与目标管理闭环跟踪成果。本页是你在本平台的起点——先看清全景，再开始协作。

为什么要做 sig 运营
社区运营团队与 SIG 协作的共识基础
统一的运营入口
所有 SIG 的推广诉求在同一平台发起，资源与节奏可统一管理，避免信息分散在群聊和邮件里。
明确的协作与审核
每一类推广内容都有固定的审核链（SIG Maintainer / 运营负责人 / 营销负责人），通过后统一进入待发布清单。
可量化的运营成果
运营计划、目标与关键结果在同一处沉淀，社区运营的价值可以被记录、复盘与放大。
资源与支撑组织矩阵
运营平台背后的协作组织，成员均支持邮件联系

sig 上线 · 推广基础文案
运营路径 / 第 2 步

新 SIG 的成立是社区生态的重要节点。统一、专业的上线推广能够：对外宣告 SIG 定位与价值，让潜在贡献者第一时间找到入口；沉淀首批物料，为后续仓开源、技术直播等活动积累传播资产；明确运营节奏，让社区、运营、营销三方在同一视图下协作。以下四类资源任选其一或组合申请，提交后将进入多角色审核流程。

仓开源 · 推广基础文案
运营路径 / 第 3 步

代码仓库开源是 SIG 从「宣告存在」走向「真正共建」的关键一跃。开源即承诺——把代码、文档与 Roadmap 公开，社区才具备可信的协作基础；开源即招募——高质量的仓库是吸引 Contributor 与 Maintainer 最直接的入口；开源即传播——配合公告、新闻稿、短视频与直播，让仓库在开源生态中被持续看见。仓开源推广的资源申请流程与 sig 上线完全一致。

运营资源申请
运营路径 / 第 4 步

通过日历选择排期，可一次勾选一天或多天，为 SIG 申请公众号、视频号、媒体渠道等推广资源，也可以申请奖品用于社区激励。提交申请时需附上对应资源的附件（附件要求随资源类型变化）。申请将进入运营负责人与营销负责人的审核链，审核通过后由运营专员在后台统一发布。
