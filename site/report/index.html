申请与审批

是所有申请的协作流转页：我提交的、待我处理、我已处理。

资源配置

供运营操作员与审核员维护渠道、反馈指标和资源可用性。

设计判断：保留统一申请，不增加重复业务页面03 / 07
核心任务流

一张申请单贯穿协作与结果

发起填写基础信息所属 SIG、标题、背景与目标
→
选择资源与排期方式 → 媒体 → 渠道 → 日期
→
提交素材与奖品按资源和排期上传材料
→
闭环审批到反馈SIG评审、运营、营销、执行、反馈

关键状态判断

“审批状态”和“当前阶段”必须分开读：审批通过后仍可能等待排期确认、发布或推广反馈。审批人与申请人回避；排期被调整时需由相关方确认。

来源：低保真申请向导与电子流交互04 / 07
